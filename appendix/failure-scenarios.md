# Сценарии проверки

| Различающая пара | Ожидание |
|---|---|
| Все узлы / любые два вычислителя выключены | Б сохраняет хотя бы одну обработку каждой из 16 камер; А при потере сервера — нет |
| Kafka доступна / ISR ниже minISR | В Б сигнал доставляется только при доступной записи/чтении; при ISR<3 новые сигналы pending, после восстановления доставляются с отметкой задержки |
| Терминал доступен / отключён | Сирена работает при отдельной исправной трассе; полноценная карточка без терминала не обещана |
| ИИ доступен / выключен | Тревога одинаково немедленная; рекомендация только в первом случае |
| Один observation_id повторён / новый ID | Повтор не новый подрепорт; новый сохраняет источник и доказательства |
| Камера отвечает ping / выдаёт свежие кадры и результат | Только второе подтверждает восстановление наблюдения |
| Команда истекла / ещё действует | Первая не исполняется; вторая проходит все локальные проверки |
| Старый epoch / новый epoch | Первый отклонён шлюзом, второй проверяется по лимитам и сроку |
| Tenant A / запрос A к данным B | Свои данные доступны; чужие отвергаются на API, БД, событиях, медиа |

В пакете реально исполняются проверки размещения, арифметики, ссылок и рендера. Остальные строки — программа испытаний реализации. Нельзя из логической модели получить измеренные 5 секунд или 99,95%.

Дополнительные пары для Б:

- RF=3/minISR=2 / RF=5/minISR=3: перебрать десять пар отказов из исходного полностью синхронного состояния; второй вариант сохраняет три ISR. Проверить служебные топики и резерв потребителей.
- Kafka восстановлена после обрыва / исторический replay: live-consumer доставляет pending; пересборка проекции не включает старую сирену.
- Терминал выключен / сирена выключена: независимые группы не блокируют исправного получателя.
- Обычная нагрузка / два узла выключены плюс догонка реплик: замерить весь P01, включая лидера и rebalance. Превышение пяти секунд — провал приёмки, не разрешённое исключение.
- ACK Kafka / подтверждённый сигнал: первое не выдаётся за второе; контролируется недоставка и возраст очереди.
- Локальный адресат / адресат вне ЛВС при WAN-обрыве: WSS доступен только локальному, удалённая доставка pending.
