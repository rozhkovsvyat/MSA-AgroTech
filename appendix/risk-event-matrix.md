# Реакция на события

| Событие | Реакция | Условие закрытия |
|---|---|---|
| Придавливание, драка, явная опасность | Немедленная местная тревога; ИИ параллельно | Подтверждённый человеком исход |
| Признаки болезни/гибели | Сообщить дежурному в P01 для нештатной видео-ситуации | Осмотр и результат |
| Камера / модель перестала наблюдать | Техническая тревога, проверка свежего видео и inference | Восстановление подтверждено; не только ping |
| Расхождение подсчёта | Проверка наблюдений и учёта | Доказанный артефакт можно закрыть без правки поголовья |
| Нет корма/воды/фильтрация нарушена | Локальная реакция, команда с допуском | Подтверждённый фактический результат |
| Ответ оборудования потерян | Unknown, проверка результата | Не равен неисполнению; не повторять полную дозу |

Отсутствие повторного обнаружения не доказывает устранение опасности. Одновременные опасности одной зоны остаются подрепортами общего инцидента, все места показываются человеку.
