# Что сохраняет локальная Kafka

Baseline [ADR 003](../ADR/003-local-kafka.md): 5 контроллеров/брокеров, RF=3, minISR=2, acks=all, unclean election выключен. Это локальная репликация, не безусловная гарантия истории.

| Случай | Результат |
|---|---|
| Нет WAN, узлы исправны | Местный журнал работает; центр догоняет позже |
| Потеря одной из трёх синхронных реплик | Две остаются, запись возможна |
| Потеря двух реплик одной партиции | ISR=1 < 2; запись останавливается, даже если кворум контроллеров есть |
| ACK получен при ISR={E1,E2}; потеря E1 и E2 до догонки E3 | Подтверждённое событие может быть потеряно |
| Все три реплики содержали событие до двух отказов | Хотя бы одна копия остаётся; доступность чтения зависит от выбора лидера |
| Гибель устройства до публикации из его буфера | Возможна потеря нереплицированного хвоста |

Три независимых распознавания не заменяют копии одинакового event_id: у каждого обработчика свой observation_id и свои факты доставки. Нельзя по их числу объявлять историю сохранённой.

История нужна для аудита обнаружения/доставки/принятия/исхода, команд оборудования, пересборки проекций, аналитики и проверки качества модели. Retention конечен: учебный горизонт локальной автономности 7 суток, события локально минимум 30 суток, центральный архив 1 год — допущения для sizing, не договорное хранение. Диск рассчитывается как поток событий × горизонт × RF + резерв; медиа отдельно. Очистка локальной истории допускается после внешней подтверждённой копии и срока, с тревогой при нехватке диска. При бесконечном WAN-обрыве конечный диск не даёт бесконечную историю.

RF=5/minISR=3 мог бы усилить отказоустойчивость подтверждённых событий, но это **не принятое изменение**, поэтому пакет описывает ограничения выбранного baseline. Дополнительное требование O01 о непрерывном распознавании при двух отказах сохраняется.

Источники: [Kafka topic configs](https://kafka.apache.org/42/configuration/topic-configs/), [KRaft](https://kafka.apache.org/42/operations/kraft/). Документ не является результатом запуска кластера.
