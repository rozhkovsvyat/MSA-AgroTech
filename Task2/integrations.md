# Контракты интеграций

| Связь | Семантика и технология | Причина / отказ |
|---|---|---|
| Камера → видеоаналитика | RTSP, camera_id, время кадра | Свежесть кадров, reconnect; видео не в Kafka |
| Б: видеоаналитика → Kafka | ObservationRecorded, ключ tenant/farm/zone, observation_id | Устойчивый буфер, acks=all; нет ACK — pending |
| Б: Kafka → оповещение | Две группы: terminal / siren; RF=5/minISR=3 | Первое наблюдение без ожидания ИИ; сбой одного канала не блокирует другой |
| Оповещение → терминал / сирена | HTTPS/mTLS / адаптер, ID и зона | Последний участок доставки; подтверждение устройства отдельно от ACK брокера |
| А: видеоаналитика → получатели / журнал | Прямой сигнал; SQL/outbox независимо | Альтернативный вариант, одна точка отказа — сервер |
| Терминал → локальный API | HTTPS, token, idempotency key | Чтение состояния синхронно; команда: 202 после постановки, исход отдельным фактом |
| Б: API → Kafka → домен | Команда с expected_version, ключ зоны/агрегата | Повтор с тем же ID, проверка версии/прав владельцем домена |
| Инциденты → Kafka / UI | Факты с aggregate_version; проекция через SSE/API | Канонический ID связывает локальные карточки; UI видит свежесть |
| API → IdP | OIDC / JWKS | Локальная проверка токена; неизвестный ключ — отказ |
| Центр → ферма | Версионированные политики/намерения с TTL, allowlist | MM2; повторная проверка прав и срока на ферме |
| Ферма ↔ центр | Б: MM2/Kafka; А: outbox/HTTPS | P02 измеряется по результату, а не одному lag |
| Б: управление → Kafka → шлюз | Разрешённая команда, command_id, expires_at, epoch | Шлюз проверяет допуск перед действием; А вызывает шлюз по HTTPS |
| Шлюз ↔ устройство | MQTT / OPC UA / Modbus через адаптер | Протокол поставщика; потерянный ответ → unknown |
| Ферма → медиасервис | HTTPS/S3, хеш, tenant/farm | Ограниченная очередь и повтор; медиа отдельно |
| Kafka → проекции / ИИ | Версия схемы, cursor, event_id | Повторы; несовместимый формат — quarantine и мониторинг |
| Интеграции ↔ ERP/BI | HTTPS API, versioned DTO | Адаптер изолирует чужую модель; без записи в доменные таблицы |

Команды, события и снимки имеют разные топики. Повтор сохраняет ID; тот же ID с иным содержимым отклоняется. Порядок держится по ключу агрегата, для наблюдений — зоны. Историческое восстановление проекций выполняется отдельной группой без внешних эффектов. Возобновление живого оповещения, напротив, обязано доставить pending; поздняя опасность показывается с временем и пометкой задержки, не исчезает из-за возраста. Kafka-позиция не заменяет версию агрегата или подтверждение получателя.
