# MSA-AgroTech

Архитектура **AgroWatch**, системы наблюдения за животными для компании «АгроТех Х»: обнаружение опасных ситуаций по видео, локальное оповещение, управление оборудованием и развитие в SaaS. Практическая работа первого спринта курса «Микросервисная архитектура».

Рассмотрены два варианта: один сервер на ферме и распределённый пул вычислителей. Выбран распределённый вариант. Фронтенд — микрофронтенды React + Vite ([ADR 007](ADR/007-microfrontends.md)); бэкенд и агенты — C#/.NET.
